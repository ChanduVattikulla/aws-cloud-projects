# 🚀 Project Flow

```text
Browser
    │
    ▼
S3 Website Endpoint
    │
    ▼
Amazon S3 Bucket
    │
    ▼
Static Website
```

# ✨ Highlights

✅ Static website hosted on Amazon S3

✅ Public access configured using Bucket Policy

✅ Built using AWS Free Tier

✅ No web server required
